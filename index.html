Política de Privacidad

En ProNeet Proxy respetamos la privacidad de nuestros usuarios y reconocemos la importancia de proteger su información. Esta Política de Privacidad explica qué datos pueden intervenir en el funcionamiento de la aplicación, cómo se utilizan las configuraciones de conexión y qué consideraciones deben tenerse en cuenta al utilizar servidores proxy.

1. Información de Configuración

ProNeet Proxy permite establecer conexiones mediante diferentes protocolos, incluyendo SOCKS5, HTTP y SSH (CDN). Para configurar una conexión, la aplicación puede procesar información técnica como direcciones IP, dominios, puertos y, cuando corresponda, credenciales de autenticación del servidor. Estos datos son necesarios para realizar las conexiones solicitadas por el usuario.

2. Uso de la Información

Los parámetros de conexión se utilizan para establecer, administrar y mantener las sesiones de red configuradas en la aplicación. Cuando el usuario introduce información de autenticación, esta puede intervenir en el proceso de acceso al servidor seleccionado. El tratamiento concreto de estos datos depende de la configuración y del método de conexión utilizado.

3. Información Almacenada en el Dispositivo

Las configuraciones, preferencias y otros ajustes que la aplicación permita guardar pueden permanecer almacenados localmente en el dispositivo para facilitar su utilización. El usuario puede gestionar los datos locales mediante las funciones disponibles de la aplicación o las opciones de almacenamiento de Android. Borrar los datos de la aplicación puede eliminar configuraciones y preferencias guardadas.

4. Conexiones Proxy y Tráfico de Red

ProNeet Proxy funciona como una herramienta para establecer conexiones a través de servidores proxy compatibles. Durante una conexión, la información necesaria para transportar el tráfico puede pasar por el servidor configurado. El tratamiento de ese tráfico también depende del protocolo utilizado, del servidor seleccionado y de los servicios de destino.

5. Servidores de Terceros

Los usuarios pueden utilizar servidores administrados por proveedores independientes. Estos servidores pueden disponer de sus propias políticas de privacidad, mecanismos de autenticación y registros técnicos. ProNeet Proxy no controla las prácticas de privacidad de servidores externos que no administra. Recomendamos utilizar únicamente servidores confiables y conocer las condiciones del proveedor correspondiente.

6. Permisos y Servicio VPN de Android

Para gestionar el tráfico de red de las aplicaciones del dispositivo, ProNeet Proxy puede utilizar la función VpnService proporcionada por Android. Este mecanismo permite crear una interfaz de red virtual y dirigir el tráfico mediante la conexión configurada. Su uso no significa que todos los protocolos proxy ofrezcan el mismo nivel de cifrado, privacidad o anonimato.

7. Estadísticas de Conexión

La aplicación puede mostrar información relacionada con el estado de la conexión, la latencia y el tráfico de datos enviado o recibido. Estos indicadores permiten al usuario supervisar el funcionamiento del servicio. Las estadísticas visibles no deben confundirse necesariamente con registros de navegación o con información que pudiera conservar un servidor externo.

8. Seguridad y Protección

La seguridad de una conexión depende de factores como el protocolo, la configuración, el servidor utilizado y el cifrado aplicado por los servicios de destino. Algunos métodos proxy no proporcionan cifrado de extremo a extremo por sí mismos. Por ello, ProNeet Proxy no garantiza anonimato absoluto ni protección total frente a los riesgos relacionados con redes o servidores de terceros.

9. Recursos de Terceros en el Sitio Web

Esta página web utiliza Google Fonts para cargar la tipografía y Font Awesome, a través de cdnjs, para mostrar iconos. Al descargar estos recursos, el navegador puede comunicarse directamente con los proveedores correspondientes y transmitir información técnica habitual de una solicitud web. Estos proveedores mantienen sus propias políticas de privacidad.

10. Enlaces y Canales de Comunicación

Nuestras páginas pueden incluir enlaces a servicios externos como WhatsApp, Telegram, Facebook, Instagram y GitHub. Cuando el usuario accede a alguno de estos servicios, su información queda sujeta a las políticas correspondientes. Si decide comunicarse voluntariamente con nosotros, los datos que proporcione podrán utilizarse para responder consultas, recibir sugerencias o atender reportes relacionados con ProNeet Proxy.

11. Conservación y Eliminación de Información

Los datos almacenados localmente pueden mantenerse mientras el usuario conserve la aplicación y sus datos. La eliminación de la información que pudiera conservar un servidor externo depende de las políticas y procedimientos de su respectivo administrador. Los usuarios deben consultar al proveedor correspondiente cuando necesiten información sobre la conservación de datos en servidores de terceros.

12. Cambios en esta Política de Privacidad

ProNeet Proxy puede actualizar esta Política de Privacidad cuando se produzcan cambios en el funcionamiento de la aplicación, en sus características o en los requisitos aplicables. Las actualizaciones serán publicadas en esta página para que los usuarios puedan consultar su contenido.
