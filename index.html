Política de Privacidad

En ProNeet Proxy reconocemos la importancia de la privacidad de nuestros usuarios. Esta política describe de forma general cómo interviene la información dentro de la aplicación y cómo se utilizan los datos relacionados con la configuración de conexión.

1. Información Utilizada y Privacidad

En ProNeet Proxy respetamos tu privacidad. La aplicación no recopila identificadores del dispositivo, ubicación ni historial de navegación para almacenarlos en servidores propios. Los datos de configuración se utilizan para establecer las conexiones que tú decides realizar.

Los únicos datos que ingresas en la aplicación (como la dirección IP o dominio, puerto, protocolo, usuario o contraseña) se guardan únicamente de forma local en tu propio teléfono y se utilizan exclusivamente para establecer la conexión a internet que tú configures.

2. Configuración Local

Para tu comodidad, ProNeet Proxy guarda dentro de tu propio dispositivo los datos de conexión que hayas ingresado (como dirección IP, puerto, protocolo o credenciales). Esta información se conserva localmente para que no tengas que escribirla de nuevo cada vez que quieras conectarte.

3. Funcionamiento de la Conexión

ProNeet Proxy te permite recibir conexión a internet mediante protocolos como SOCKS5, HTTP y SSH (CDN). Mientras el servicio esté activo, el tráfico de red de tu dispositivo circulará únicamente hacia el teléfono emisor o servidor que tú hayas configurado, sin pasar en ningún momento por servidores propios de nuestra aplicación.

4. Permisos de Android

Para poder brindarte el servicio, ProNeet Proxy únicamente solicita permiso de conexión VPN (necesario para recibir y gestionar el tráfico de red en tu teléfono) y permiso de notificaciones (para mostrarte el estado de la conexión y mantener el servicio activo). Ninguno de estos permisos se utiliza para acceder a tu información personal ni para recopilar datos de tu dispositivo.

5. Información de Tráfico

Mientras estés conectado, ProNeet Proxy puede mostrarte en pantalla contadores visuales de los datos enviados y recibidos para que puedas controlar tu consumo en tiempo real. Este conteo se calcula únicamente dentro de tu dispositivo y no se registra, almacena ni envía a ningún servidor externo.

Esta función tiene un propósito informativo dentro de la interfaz y no representa por sí sola un historial detallado de navegación.

Por este motivo, se recomienda utilizar únicamente servidores confiables y adecuadamente autorizados.

6. Cambios en esta Política

Esta Política de Privacidad podrá actualizarse cuando se incorporen nuevas funciones o se realicen cambios relevantes en el funcionamiento de la aplicación. Las versiones actualizadas estarán disponibles para su consulta por los canales oficiales de ProNeet Proxy.
